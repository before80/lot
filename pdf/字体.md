
思源字体
下载地址：https://github.com/adobe-fonts/source-han-sans/releases
选择：Language Specific OTFs Simplified Chinese (简体中文) 


使用pip安装otf2ttf: 

```shell
pip install otf2ttf

```

使用otf2ttf转换otf字体为ttf字体
例如：

```shell
cd .\fonts
otf2ttf SourceHanSansSC-Light.otf
otf2ttf SourceHanSansSC-Bold.otf
```

这样在fonts目录中就会生成SourceHanSansSC-Light.ttf和SourceHanSansSC-Bold.ttf文件
